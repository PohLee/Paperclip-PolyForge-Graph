# Upstream method routing

This directory contains pack-owned adapters, not upstream runtime wrappers.

- `designer-skills` contributes scoped research, UX strategy, interaction, system, critique, and handoff methods to matching graph nodes.
- `taste-skill` contributes optional visual direction and page/app-specific craft considerations. It never overrides an approved project brand or confirmed requirement.
- `impeccable` contributes selected new-work, visualize, critique, audit, polish, harden, adapt, and documentation methods. Each remains conditional on the node and available host capability.

Adapters first resolve `explorationMode` (`brand-territory`, `product-structure`, `surface-composition`) and the brief's `surfaceMode` taxonomy. Map `persuade` to Taste's public page profile and `operate` to its work-app profile. For `read`, inherit the kind of the existing surface under inspection. For `experience`, use the target surface: app profile for task-driven interaction, page profile for primarily editorial or public-facing experiences. Strategy-only briefs may leave `surfaceMode` null; the runtime wrapper requires a concrete mode for G03, G04, and G05. Brand territory varies visual language with strategy held fixed; product structure varies IA/task expression with product facts fixed; surface composition varies hierarchy and composition with selected concept and function fixed. For the app profile, omit page-only motion or imagery rules; for the page profile, use those only when content and accessibility support them.

Precedence: confirmed requirements and approved brand promise, then platform/accessibility/business constraints, approved design baseline, modes, specialized craft guidance, and optional taste preferences. Record source IDs and adapter revision when adapted methods materially shape the output. Do not install or run upstream binaries, scripts, hooks, or services.
