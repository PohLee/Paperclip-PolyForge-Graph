# Concept sprint and gallery

First freeze one brief and comparison basis. Respect count 3–5; default to 3 and expand only for real uncertainty. Give each candidate a distinct design hypothesis, stable ID, equal content, target dimensions, and comparable finish. Generate actual static images; inspect each image for decoding, subject, and duplication. Deliver one HTML gallery with each static image, an 80–120 word introduction, three key choices, a suitable use case, and one honest tradeoff. Include zoom and comparison only; the gallery does not represent interactive prototypes. If image generation is unavailable, report the capability gap instead of substituting text or a product page.
